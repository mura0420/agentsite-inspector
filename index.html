How it works

Reads like a caller

It fetches the manifest, each network definition and links.json with plain GET requests and no credentials, from this page's origin. If this page can read them, any agentic website can.

Validates like the runtime

Networks are parsed and validated by the reference browser runtime's own HOCON parser and validator, then checked for the MVP rules on content, data-only publishing, credentials, peers and MCP.

Asks before it reaches out

Peer networks are listed but never fetched on their own. Each new origin is an inspection you start, and the assistant asks you on a card before it contacts one.

Every finding links to the spec section it comes from and says how to fix it. The same checks run in CI: node cli/inspect.mjs https://your-site.example/ --badge badge.svg.

Ask the inspector

This page is itself an open agentic website. Its assistant can run an inspection for you, explain each finding with the spec section behind it, and draft the exact manifest or network change that fixes it.

Your messages and this page's data go to the LLM provider you choose in the settings below. Before the assistant contacts another site, you confirm it.
